# Gym tracker Document

Halo selamat datang di gym tracker document, disini kami membuat app untuk menyusun jadwal latihan,penghitungan repestisi,dan penyimpanan aktivitas harian

## Tech stack
Kami menggunakan monorepo 
Monorepo (singkatan dari monolithic repository) adalah strategi manajemen kode di mana seluruh kode sumber untuk berbagai proyek, aplikasi, atau library yang berbeda disimpan dalam satu repositori terpusat yang sama

### Backend developer
di bagian backend kami menggunakan framework laravel untuk integrasi api

![Laravel](https://img.shields.io/badge/laravel-%23FF2D20.svg?style=for-the-badge&logo=laravel&logoColor=white)

### Frontend Developer
dan di bagian frontend kami menggunakan framework next.js untuk ui yang bersih dan pengalaman yang baik
